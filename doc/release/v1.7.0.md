## English

### Projects
- A game is a folder with a `cyd_project.ini` (main file, target, paths and options). Create one with `make_adventure.py --new FOLDER [TARGET]`, or with *New…* in the GUI.
- `make_adv.cmd` / `make_adv.sh` take the project folder as an argument (on Windows you can drop the folder onto `make_adv.cmd`), and the GUI opens projects and remembers the recent ones. CYD's own folder is no longer a game.
- The output goes to the project's `OUTPUT` folder; intermediate files to `OUTPUT/cyd_tmp` (kept with `--keep-temp`) and the compressed images to `OUTPUT/cyd_cache`, so unchanged images are not compressed again.
- The loading screen is `IMAGES/LOAD.scr` everywhere by default.

### Language and compiler
- `INCLUDE LIB "file.cyd"` includes a bundled library (or one from your library folders). A plain `INCLUDE` looks next to the file, then in the project root, then in the include folders. A library included twice is included once.
- Search folders for each case: `-I` / `--include-path`, `--lib-path`, `--import-path` (and `include_paths`, `lib_paths`, `import_paths` in `cyd_project.ini`).
- Messages start with the place, relative to the project: `ERROR [PARSER] chapters/one.cyd:12:5: ...`. The VS Code highlighter 2.7.0 reads this format.
- Strict colon mode now also requires the colon after text and after multi-line statements (before, only the first code block was checked).
- Native routines (`IMPORT` / `CALL`, `ASM`) verified on all six targets, esxdos included.
- `MENUKEY action, key` changes the menu keys and `MENUJOY type` adds a Sinclair (port 1 or 2) or cursor joystick, which works at the same time as the keyboard. The settings live in the interpreter: they take no variables.
- The menus no longer select with `M` (use `SPACE`, `ENTER` or the key set with `MENUKEY`), and the Kempston fire button now also turns the page when a page pause waits.
- Fixed: a file included twice was reported as a circular include; `-T`, `-t`, `-C` and `-c` in `make_adventure.py` didn't reach the compiler.
- Fixed on MLD (Dandanator): the cursor keys (CAPS SHIFT + 5 to 8) and SYMBOL SHIFT with a letter gave wrong codes, so the cursor keys did not move the menus.

### Documentation and tools
- The manuals and tutorials are now at https://cronomantic.github.io/ChooseYourDestiny/ (the wiki is retired), with the code highlighted.
- Manuals and tutorials reviewed against the compiler: examples that did not compile, wrong values and missing parts fixed; the tutorial now covers `DO … UNTIL`.
- The Windows package includes Python 3.15.2 (Tcl/Tk 9).
- `examples/Delerict` is now a small but complete adventure, with pictures of its ten locations.

## Español

### Proyectos
- Un juego es una carpeta con un `cyd_project.ini` (fichero principal, target, rutas y opciones). Se crea con `make_adventure.py --new CARPETA [TARGET]`, o con *Nuevo…* en la GUI.
- `make_adv.cmd` / `make_adv.sh` reciben la carpeta del proyecto como argumento (en Windows puedes soltar la carpeta sobre `make_adv.cmd`), y la GUI abre proyectos y recuerda los recientes. La carpeta de CYD ya no es un juego.
- La salida va a la carpeta `OUTPUT` del proyecto; los ficheros intermedios a `OUTPUT/cyd_tmp` (se conservan con `--keep-temp`) y las imágenes comprimidas a `OUTPUT/cyd_cache`, así que las imágenes que no cambian no se vuelven a comprimir.
- La pantalla de carga es `IMAGES/LOAD.scr` en todas partes por defecto.

### Lenguaje y compilador
- `INCLUDE LIB "fichero.cyd"` incluye una librería de las que trae CYD (o de tus carpetas de librerías). Un `INCLUDE` normal busca junto al fichero, después en la raíz del proyecto y después en las carpetas de include. Una librería incluida dos veces se incluye una sola vez.
- Carpetas de búsqueda para cada caso: `-I` / `--include-path`, `--lib-path`, `--import-path` (e `include_paths`, `lib_paths`, `import_paths` en `cyd_project.ini`).
- Los mensajes empiezan por el sitio, relativo al proyecto: `ERROR [PARSER] capitulos/uno.cyd:12:5: ...`. El resaltador de VS Code 2.7.0 lee este formato.
- El modo estricto de dos puntos los exige también después de texto y de sentencias de varias líneas (antes solo se comprobaba el primer bloque de código).
- Rutinas nativas (`IMPORT` / `CALL`, `ASM`) verificadas en los seis targets, esxdos incluido.
- `MENUKEY accion, tecla` cambia las teclas de los menús y `MENUJOY tipo` añade un joystick Sinclair (puerto 1 o 2) o de cursor, que funciona a la vez que el teclado. La configuración vive en el intérprete: no ocupa variables.
- Los menús ya no seleccionan con `M` (se usa `ESPACIO`, `ENTER` o la tecla puesta con `MENUKEY`), y el disparo del Kempston pasa también de página cuando hay una pausa de página.
- Corregido: un fichero incluido dos veces se daba por include circular; `-T`, `-t`, `-C` y `-c` de `make_adventure.py` no llegaban al compilador.
- Corregido en MLD (Dandanator): las teclas de cursor (CAPS SHIFT + 5 a 8) y SYMBOL SHIFT con una letra daban códigos erróneos, así que las teclas de cursor no movían los menús.

### Documentación y herramientas
- Los manuales y tutoriales están ahora en https://cronomantic.github.io/ChooseYourDestiny/ (la wiki se retira), con el código coloreado.
- Manuales y tutoriales revisados contra el compilador: corregidos ejemplos que no compilaban, valores erróneos y partes que faltaban; el tutorial explica ya `DO … UNTIL`.
- El paquete de Windows incluye Python 3.15.2 (Tcl/Tk 9).
- `examples/Delerict` es ahora una aventura pequeña pero completa, con imágenes de sus diez localidades.
